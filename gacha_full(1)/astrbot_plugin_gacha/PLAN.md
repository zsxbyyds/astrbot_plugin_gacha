# 抽卡机 → 游戏化 设计方案（定稿）

## 定稿修改点（小南瓜已确认）
- 所有功能同步上 WebUI
- 战力三维：攻 / 防 / 血
- 重复卡转碎片，同名卡升阶
- 体力随时间回复
- 副本后续可加属性克制
- 感情对话副本：AI 下场实时对话，达成目标给感情点数，可加到指定卡上
- 指令同步到 UI

## 资源体系
- 肥鱼币、经验书、突破素材（三/四/五星三档）、体力
- 体力随时间回复，打副本消耗

## 养成
- 每张卡：等级、经验、突破阶段、三维（攻/防/血）
- 等级上限按星：三星 50、四星 70、五星 90
- 关键等级突破，吃对应星级素材
- 战力 = 星级基础 × 等级 × 突破倍率，拆成攻防血三个数
- 重复卡→碎片，碎片升阶

## 每日任务
- 签到（已有）
- 抽 1 次、打 1 次副本、上阵 3 角色、收 1 次掉落
- 各给资源，每天 0 点刷新

## 副本
- 三关：鱼塘清扫、沉船探宝、深海首领，难度递增
- 选 3 张上阵，按三维算战力
- 战力够就赢，带随机浮动，掉经验书/币/素材，耗体力
- 感情对话副本：AI 下场跟玩家实时对话，聊到目标达成给感情点数，玩家加到喜欢的卡上

## 指令（全部同步 UI）
- 聊天：/养成 /突破 /碎片 /上阵 /队伍 /副本 /每日任务 /战力 /感情副本
- UI：我的角色、副本、任务、感情 页签

## UI 规划
- 主页加页签：抽卡 / 角色 / 副本 / 任务 / 感情 / 图鉴 / 排行

## 开发顺序
1. 资源 + 养成（三维）+ 碎片 + 战力
2. 每日任务
3. 副本 + 体力 + 战斗结算
4. 感情对话副本 + 感情点数
5. UI 全部同步 + 战力榜 + 非酋榜

进度会随时同步给小南瓜。
