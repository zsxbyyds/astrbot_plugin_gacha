# 抽卡机版本记录

git 仓库就在本插件目录，以后说 tag 名即可。

## 版本
- `v1-text`：纯文字版（第一版），卡池不带卡图，只有名字+描述
- `v2-card`：卡图版（旧方案），把图片转 base64 塞进卡池接口，接口体积大，不推荐
- `v3-card`：卡图版，图片走 views 静态资源相对路径，图文都显示，接口干净
- `v4-text`：卡池文字版（当前推荐），卡池只显示名字+描述，图鉴/收集保留卡图
- `v5-affection`：加好感度系统、非酋榜、五星出货动画、感情副本（AI 下场谈心）
- `v6-bond`（最新）：加每日免费一抽、抽卡记录、编队羁绊、好感专属对话

## v6-bond 都加了啥
- 每日免费一抽：每天 0 点送 1 次，`/免费抽` 或看板「免费一抽」按钮抽，不扣抽数
- 抽卡记录：每次抽卡留档最近 50 条，`/抽卡记录` 看最近 10 条 + 保底进度，看板「我的收集」里同步展示
- 编队羁绊：三人满编 +5%、两卡同元素 +8%、三卡同元素 +12%，战力直接乘进去；`/队伍` `/战力` 会显示羁绊
- 好感专属对话：每张卡好感 20/50/80 各解锁一句专属台词，`/摸摸` 跨档自动展示，`/台词 卡名` 查看
- 图鉴收集奖励这轮之前已做（/成就、收集成就），本轮未改动

## v5-affection 都加了啥
- 好感度：每张卡 0~100，每 10 点三维 +2%；上阵出战胜利 +3、每天 /摸摸 一次 +2、感情副本聊满结算 +10
- 感情副本：/感情副本 卡名 开始，/说 想说的话 跟角色聊，AI 扮演卡牌角色实时回复，聊满 5 轮自动结算好感；/结束感情 退出
- 非酋榜：抽满 10 次还没五星的倒霉蛋，跟欧皇排行并排展示
- 出货动画：看板抽到五星落地闪一下

## 图片文件
- `cards/*.png`：v2 旧方案用的源图，一直留着没删
- `views/gacha/cards/*.png`：图鉴用的图，前端按相对路径 `cards/xxx.png` 加载

## 怎么回退 / 参考
- 当前最新卡池文字版：`git checkout v4-text`
- 卡图版：`git checkout v3-card`
- 旧 base64 卡图版：`git checkout v2-card`
- 第一版纯文字：`git checkout v1-text`
- 回到最新：`git checkout master`

改完要生效：AstrBot 里重载抽卡机插件，浏览器 Ctrl+F5 硬刷页面。
